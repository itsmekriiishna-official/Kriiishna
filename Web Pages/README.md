# Web Pages

This is the canonical webpage tree for the portfolio. Each route owns an `index.html`; shared presentation and behavior live in `styles.css` and `app.js` at this level.

```text
Web Pages/
├── index.html
├── styles.css
├── app.js
├── home/
│   └── experiments/
├── about/
├── work/
├── tools/
│   └── design/
├── cursors/
│   └── collections/
└── resources/
```

The root `index.html` remains the public home entry point. Existing root-level section folders are retained as compatibility routes while the `Web Pages/` tree is organized and expanded.
